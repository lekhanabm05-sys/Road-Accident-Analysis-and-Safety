# Road Accident Analysis and Safety Dashboard

## Project Overview
This project analyzes road accident data using Tableau Public.
The dashboard helps users explore accident patterns based on
severity, vehicle type, speed limit, weather conditions,
road surface conditions, light conditions, month, and location.

## Objectives
- Analyze accident severity.
- Identify vehicle categories frequently involved in accidents.
- Study weather and road surface conditions.
- Compare accidents under different light conditions.
- Analyze monthly accident trends.
- Visualize accident locations using a map.
- Create an interactive Tableau dashboard.

## Tools and Technologies
- Tableau Public
- Microsoft Excel / CSV
- Kaggle Road Accident Dataset
- Git and GitHub

## Dashboard Features
- Total accident KPI
- Accident severity analysis
- Speed limit analysis
- Vehicle type analysis
- Weather conditions analysis
- Road surface conditions analysis
- Light conditions analysis
- Monthly accident trend
- Accident location map
- Interactive filters

## Dataset
The dataset was obtained from Kaggle.

## Project Outcome
The dashboard presents road accident information through
interactive visualizations, helping users explore patterns
and identify areas that may require further road-safety analysis.
